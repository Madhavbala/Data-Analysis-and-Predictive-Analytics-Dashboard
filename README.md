Data Analysis and Prediction Dashboard
Welcome to the Data Analysis and Prediction Dashboard! This application allows you to explore, analyze, and visualize data, especially related to insurance. You can also make predictions based on the data you upload.

Features
Upload Data: Easily upload your CSV file containing insurance data.
Data Overview: Get a quick look at your data, including its size and basic statistics.
Visualizations: Create different types of plots (like scatter plots, bar charts, and heatmaps) to see trends and relationships in your data.
Predictive Analytics: Choose a target variable and features to build predictive models using:
Linear Regression
Random Forest
Support Vector Regression (SVR)
How to Use
Upload Your Data: Start by uploading a CSV file in the "Data Overview" section.
Explore Your Data: View the data shape and summary statistics to understand its contents.
Create Visualizations: Go to the "Visualizations" section to generate plots based on your data.
Make Predictions: In the "Predictive Analytics" section, select a target variable and features to train a model and make predictions.
